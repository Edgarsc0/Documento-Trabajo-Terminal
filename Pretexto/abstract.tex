\begin{center}
    \bfseries RESUMEN
\end{center}

\vspace{0.5em}

\noindent
Este trabajo propone desarrollar un prototipo de modelo para la generación
automática de pódcast a partir de noticias digitales, las cuales se recopilan
mediante canales RSS y se almacenan en una base de datos. A partir de una
consulta realizada mediante una interfaz web y con el apoyo de técnicas de
Procesamiento del Lenguaje Natural, se genera un guion para un pódcast que
posteriormente es convertido en audio mediante síntesis de voz. Este
prototipo busca ofrecer una alternativa para facilitar el acceso al contenido
informativo publicado por medios digitales.
