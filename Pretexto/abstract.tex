\begin{center}
    \bfseries RESUMEN
\end{center}

\vspace{0.5em}

\noindent
Este Trabajo Terminal propone diseñar e implementar un General Game Player (GGP) para juegos discretos, deterministas, por turnos y de información perfecta. La idea es separar las reglas de cada juego del motor de decisión del agente mediante un lenguaje de descripción externo. A partir de ese lenguaje, el sistema interpretará la estructura del juego, construirá una representación interna, generará los movimientos legales, aplicará transiciones, reconocerá los estados terminales y elegirá acciones con algoritmos generales de búsqueda. El proyecto se validará con el Gato, como caso funcional completo, y con escenarios controlados de Ajedrez, para observar qué tanto generaliza el enfoque sin modificar el núcleo algorítmico del agente.
